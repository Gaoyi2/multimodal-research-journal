一、基础入门
git init                  # 初始化本地git仓库
git clone 地址            # 拉取整个仓库到本地
git status                # 查看当前状态（最常用）
git add .                 # 所有改动加入暂存区；也可以 git add xxx.py
git commit -m "feat: 新增登录"  # 暂存区提交到本地仓库，生成commit快照
git log                   # 查看提交历史  q退出
git log --oneline         # 简洁一行式日志（面试优先说这个）
git diff                  # 工作区 vs 暂存区，看代码改动
git diff --cached         # 暂存区 vs 本地仓库

二、分支操作（重中之重）

git branch                # 查看本地分支
git branch dev            # 创建dev分支（不切换）
git switch dev            # 切换分支（新版推荐，替代checkout）
git switch -c feature/xxx # 创建并切换到新分支（=老版 git checkout -b）
git merge dev             # 将dev合并到**当前分支**，生成merge提交，不修改历史
git rebase dev            # 变基，把当前分支提交“嫁接”到dev最新节点，**重写commit哈希**
git branch -d dev         # 删除本地分支（安全，已合并才能删）
git branch -D dev         # 强制删除本地未合并分支


三、远程协作

git remote -v                 # 查看远程仓库
git remote add origin xxx.git # 绑定远程地址
git fetch origin              # 拉远程更新到本地远程追踪分支 origin/main，**不自动合并，安全**
git pull origin main          # = fetch + merge；拉远程并合并到当前分支
git pull --rebase origin main # = fetch + rebase，拉取时变基
git push origin main          # 推送本地分支到远程
git push origin --delete dev  # 删除远程分支
git push -f                   # 强制推送（危险！rebase后才用，公共分支严禁）

四、撤销、回滚

git stash                 # 临时保存当前未提交的改动，工作区变干净
git stash list            # 查看所有stash快照
git stash pop             # 取出最近一条stash并删掉记录（最常用）
git stash apply stash@{0} # 取出stash，保留stash记录
git stash drop stash@{0}  # 删除指定stash


五、Stash 暂存

git stash list            # 查看所有stash快照
git stash pop             # 取出最近一条stash并删掉记录（最常用）

六、进阶高频

git cherry-pick commitId  # 单独把某一条commit，复制到当前分支（只拿单个提交，不是整个分支）
git bisect start          # 二分查找，定位哪个commit引入bug（bug排查神器）
git blame xxx.py          # 看文件每一行是谁、哪个commit修改的
git rebase -i HEAD~3      # 交互式变基：合并、修改、删除最近3条commit（squash压缩提交）
